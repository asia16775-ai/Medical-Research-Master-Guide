Core Principles

8 บทเรียนทองคำจากคณาจารย์ผู้ทรงคุณวุฒิ

1

ปรัชญา GIGO (Garbage In, Garbage Out)

คุณภาพของผลวิจัยขึ้นอยู่กับ Methodology และกระบวนการเก็บข้อมูล หากกลุ่มตัวอย่างมีอคติ (Selection Bias) หรือเครื่องมือไม่ตรงกับบริบท ต่อให้ใช้สถิติพหุตัวแปรขั้นสูง (Multiple Logistic, Machine Learning) ผลลัพธ์ที่ได้ก็ยังคงเป็น "ข้อมูลขยะที่ใช้ตัดสินใจทางคลินิกไม่ได้"

2

กับดักการตัดทอนข้อมูล (Dichotomization Trap)

ข้อผิดพลาดที่อาจารย์ติงหนักที่สุด: การนำคะแนน Likert Scale (1-5) หรือตัวแปรต่อเนื่อง มาหั่นเป็น 0 กับ 1 (Binary) เพื่อทำ Logistic Regression ทำให้สูญเสีย Variance มหาศาล ลดทอน Power เท่ากับทิ้งกลุ่มตัวอย่างไป 1/3 และเสี่ยงถูก Reviewer มองว่าทำ P-hacking ควรใช้ Multiple Linear Regression

3

Subgroup Analysis vs "การจับแพะชนแกะ"

เมื่อภาพรวมไม่ซิก การทำ Subgroup Analysis (เช่น ปรีคลินิก vs คลินิก) ทำได้แต่ต้องระวัง Sample size ย่อยเล็กลง ส่วน "การจับแพะชนแกะ (Data Fishing / HARKing)" โดยลองจับคู่ตัวแปรไปเรื่อยๆ จนเจอ p < 0.05 แล้วเอามาพรีเซนต์ เป็นข้อห้ามร้ายแรงเพราะเพิ่ม Type I Error พุ่งสูง

4

การดัดแปลงเครื่องมือวัด (Re-validation Trap)

การนำแบบสอบถามมาตรฐานสากล (MSLQ, MSPSS, CBI) มาแปลหรือปรับข้อความให้เข้ากับบริบท PBL ห้ามนำไปเก็บข้อมูลจริงทันที! ต้องนำไปให้ผู้เชี่ยวชาญ 3-5 ท่านตรวจ Content Validity เพื่อหา IOC (≥ 0.50) และทำ Pilot Study หา Cronbach's Alpha (≥ 0.70) ซ้ำเสมอ

5

Sphericity & Statistical Assumptions

ก่อนใช้ Repeated Measures ANOVA ต้องตรวจ Normality ด้วย Shapiro-Wilk (p > 0.05) และตรวจความเท่าเทียมของความแปรปรวนผลต่างด้วย Mauchly's Test of Sphericity หากละเมิด (p < 0.05) ต้องปรับ Degrees of Freedom ด้วยค่าแก้ Greenhouse-Geisser

6

Range Restriction Phenomenon

การที่คะแนนสอบคัดเลือก (TCAS/กสพท) สัมพันธ์กับเกรดแพทย์น้อย เกิดจาก Range Restriction เพราะเราศึกษาเฉพาะคนที่สอบติดเข้ามาแล้ว คะแนนจึงกระจุกตัวอยู่ช่วงบน ไม่มีความแปรปรวนเต็มช่วง ทำให้ค่า r และ R² ต่ำกว่าความเป็นจริงในประชากรผู้สมัคร

7

Prediction Models: Discrimination vs Calibration

โมเดลพยากรณ์ที่ดีต้องรายงาน 2 มิติ: Discrimination (AUC-ROC / C-statistic) ต้องมี 95% CI ไม่ครอบคลุม 0.50 และ Calibration (Hosmer-Lemeshow / Calibration Plot) เพื่อดูความแม่นตรง และต้องคุม Events Per Variable (EPV ≥ 10) ป้องกัน Overfitting

8

การเตรียมความพร้อมนำเสนอผลงาน TMEC

คณะแพทยศาสตร์ ม.บูรพา เป็นเจ้าภาพจัด TMEC: สำหรับ e-Poster ต้องกระชับ มีผังมโนทัศน์ ตารางผลลัพธ์หลักไม่เกิน 2-3 ตาราง ส่วน Oral Presentation ต้องซ้อมพูดให้ตรงเวลา สบตากรรมการ ไม่ก้มอ่านสไลด์ และเน้นย้ำคุณค่าทางการแพทย์

Room 516 Presentations

ถอดรหัสงานวิจัยและการวิพากษ์: ห้อง 516

กลุ่ม 5 Experimental / Pre-Post / ANCOVA

การเปรียบเทียบประสิทธิผลของการทบทวนคำศัพท์แพทย์ด้วย AI Gemini (Recognition vs Recall) ภายใต้ Spaced Repetition ในนิสิตแพทย์ปี 3

เครื่องมือและแบบทดสอบ: ใช้ Extended Matching Questions (EMQ) มีตัวเลือก 8-15 ข้อ ช่วยลด Guessing effect เมื่อเทียบกับ MCQ ทั่วไป

สถิติและการวิพากษ์: คะแนน Pre-test สองกลุ่มไม่เท่ากัน (Baseline imbalance) ผู้วิจัยเลือกใช้ ANCOVA ปรับค่า Baseline ได้อย่างถูกต้อง แต่อาจารย์ตั้งคำถามเรื่อง นิยามของ Long-term retention ว่าควรวัดผลซ้ำที่ 4-8 สัปดาห์

กลุ่ม 1 Cross-sectional / Multiple Linear Regression

ปัจจัยที่มีความสัมพันธ์กับทักษะการคิดเชิงวิพากษ์ (Critical Thinking) ในการใช้ Generative AI ของนิสิตแพทย์ไทย

ตัวแปร: ชั้นปี (ปี 2-6, ปรีคลินิก vs คลินิก), Generative AI Literacy, ความถี่การใช้, และความเชื่อมั่น (Trust)

ประเด็นวิพากษ์: การเก็บแบบสอบถามออนไลน์เสี่ยงต่อ Volunteer Bias (ผู้ตอบมักเป็นคนที่ใช้ AI อยู่แล้ว) และในโมเดล Regression ต้องระวัง Multicollinearity ระหว่าง Trust กับ Literacy โดยต้องเช็คค่า VIF < 5-10 เสมอ

กลุ่ม 2 Correlational / Reverse Causality

Active Learning และ Academic Self-Efficacy กับผลสัมฤทธิ์ทางการศึกษาของนักศึกษาแพทย์ปรีคลินิก

ประเด็นวิพากษ์: Cross-sectional study มีปัญหา Reverse Causality (ไก่กับไข่) ไม่สามารถบอกได้ว่า Self-efficacy ทำให้เกรดดี หรือเกรดดีทำให้มั่นใจ นอกจากนี้นิสิตปี 1 ได้คะแนน Self-efficacy ต่ำสุดเนื่องจากอยู่ในช่วงรอยต่อการปรับตัว (Transition Period Effect)

กลุ่ม 4 CBI Burnout / The Dichotomization Trap

ปัจจัยเสี่ยงและปัจจัยป้องกันต่อภาวะหมดไฟ (Burnout) ในนิสิตแพทย์ด้วยแบบประเมิน CBI

จุดที่อาจารย์ติงเข้มงวดที่สุด: นิสิตแปลงคำตอบ Likert 5 ระดับเป็น 0 กับ 1 (Yes/No) เพื่อทำ Logistic Regression อาจารย์ทักว่าทำให้สูญเสีย Variance มหาศาลและลด Power ควรใช้ Multiple Linear Regression กับคะแนนต่อเนื่องเดิม และแบบสอบถามปัจจัยเสี่ยงที่สร้างขึ้นมาใหม่ต้องทำ IOC และ Pilot test เสมอ

Room 601 Presentations

ถอดรหัสงานวิจัยและการวิพากษ์: ห้อง 601

กลุ่มบุคลิกภาพเฉพาะทาง Mini-IPIP / Discrete Choice Experiment (DCE)

บุคลิกภาพ Big Five (Mini-IPIP) กับการตัดสินใจเลือกสาขาเฉพาะทางของแพทย์ไทยด้วยวิธี DCE

วิธีวิทยา: Discrete Choice Experiment จำลองสถานการณ์ให้เลือกโดยชั่งน้ำหนักระหว่าง Attributes (ผลตอบแทน ชั่วโมงเวร ความก้าวหน้า) เพื่อหาค่า Preference และ Trade-off

ข้อวิพากษ์: ต้องระวัง Selection bias จากกลุ่มตัวอย่างอาจารย์แพทย์แต่ละสาขาที่มีขนาดเล็ก และต้องมีกรอบทฤษฎีจิตวิทยารองรับที่ชัดเจน

กลุ่ม 6 Retrospective Cohort / Clinical Prediction Model

การพัฒนาแบบจำลองการทำนายทางคลินิก (Clinical Prediction Model) จากข้อมูลเวชระเบียนย้อนหลัง

ข้อวิพากษ์: ข้อมูลย้อนหลังมีปัญหา Missing Data โมเดลเสี่ยงต่อ Overfitting (แม่นยำสูงใน Derivation set แต่แย่ใน Validation set) ต้องทำ Internal Validation ด้วย Bootstrapping และรายงานทั้ง Discrimination (AUC-ROC) และ Calibration (Hosmer-Lemeshow)

กลุ่ม 10 Crossover / Two-way Repeated Measures ANOVA

Active Break vs Passive Break ต่อความเหนื่อยล้าและการรู้คิด (Stroop Reaction Time)

การทดสอบ Assumption: ได้รับคำชมเรื่องการตรวจ Shapiro-Wilk แต่ต้องตรวจ Mauchly's Sphericity ด้วย

Carryover Confounder: พบว่า Reaction time เริ่มต้นของวันหนึ่งสูงผิดปกติเนื่องจากเป็นวันหลังสอบบล็อกคาร์ดิโอ ต้องแก้ด้วย Counterbalancing และกำหนด Washout period

กลุ่ม 8 G*Power / PBL Impostor / Hierarchical Regression

Academic Self-Efficacy (MSLQ), Social Support (MSPSS) กับ Impostor Phenomenon ในบริบท PBL

Sample Size & Dropout: คำนวณ G*Power ได้ 96 คน สูตรเผื่อ Dropout 10% คือ 96 / (1 - 0.10) = 107 คน

Re-validation Trap: ปรับคำถามให้เข้ากับบริบท PBL ต้องตรวจ IOC และทำ Pilot study หา Cronbach's alpha ซ้ำเสมอ

กลุ่ม 7 ROC Curve / Youden's Index / Range Restriction

คะแนนสอบคัดเลือก (TCAS/กสพท) กับผลการเรียนแพทย์ และการหา Cut-off ด้วย ROC Curve

Range Restriction: คะแนนคัดเลือกสัมพันธ์กับเกรดแพทย์น้อยเพราะกลุ่มตัวอย่างถูกคัดกรองมาแล้ว (ทุกคนคะแนนสูง)

ROC & Youden's Index: หา Optimal cut-off จาก J = Sensitivity + Specificity - 1 โดย 95% CI ของ AUC ต้องไม่คร่อม 0.50
